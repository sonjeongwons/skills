## 롤백 기록

> 유형: R1 재인터뷰 / R2 재합의 / R3 재설계 / R4 기능 되돌리기 / R5 갈아엎기
> 롤백 전에 `git tag rollback-<번호>-before`로 보존하고, 대체된 결정은 지우지 말고 "대체됨 → R번호"로 표시한다.
