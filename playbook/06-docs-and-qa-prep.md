# 06. 문서 마무리·서술형 대비 (150~170분)

## 목표
README가 요구하는 필수 문서를 완성하고, AI 없이 내 결과물을 설명할 준비를 한다.

## 할 일
- [ ] README가 정한 필수 문서·파일명 다시 확인 → 템플릿 내용을 해당 파일로 옮기기
- [ ] 문서에는 반드시: 선택한 판단과 근거, 검증 결과, 남은 한계 (가이드가 명시한 항목)
- [ ] `HANDOFF.md` 최종 갱신 (`skills/handoff`)
- [ ] 서술형 리허설 (`skills/followup-qa-prep`): Codex에게 예상 질문 6개를 받고, 답은 내가 직접 쓰고, 코드와 다른 부분만 지적받기
- [ ] 핵심 파일명·함수명·포트·데이터 흐름을 소리 내어 한 번 말해 보기 (서술형은 복붙 불가)
- [ ] 커밋

## 종료 조건
- 필수 문서가 모두 있고 저장됨 상태다.
- 예상 질문 6개에 각각 30초 안에 첫 문장을 말할 수 있다.

## 남길 증거 → 평가 기준
- 필수 문서(계획·협업 기록 등) → 의도·인지 전반
- `HANDOFF.md` → 인지: 실제 구성과 동작 이해, 한계 예측 / (FDE 트랙의 경우) 소통

## 하지 말 것
- 문서를 AI에게 통째로 쓰게 하고 읽지 않기. AI 도움은 불이익이 없지만, 내용이 실제 구현과 다르면 서술형에서 드러난다.
- 이 단계에서 기능 추가.

## 롤백이 있었다면 문서에 남길 것
- `DECISIONS.md` 롤백 기록이 실제 커밋·태그와 맞는지 확인한다.
- 필수 문서(계획·협업 기록 등)에 "처음 계획 → 바꾼 이유 → 바뀐 계획"을 짧게 쓴다. 판단의 변화가 보이는 것이 좋다.
- `VERIFICATION.md`에서 "재검증 필요"로 남은 행을 다시 실행하거나, 못 했으면 그대로 한계로 둔다.
