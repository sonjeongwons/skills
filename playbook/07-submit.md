# 07. 제출 (170~180분)

## 할 일 (`skills/pre-submit-check` 참고)
- [ ] 모든 에디터 탭이 "저장됨"인지 확인. "외부 변경 감지"가 있으면 내용 비교 후 선택
- [ ] 필수 파일 경로·이름이 README와 정확히 일치하는지
- [ ] `git status`가 깨끗한지, 마지막 커밋: `git add -A && git commit -m "docs: 제출 전 최종 정리"`
- [ ] `.env`, 키, 대용량 임시 파일이 작업 폴더에 없는지
- [ ] 상단 "제출하고 문제풀기" → 미리보기 확인 (미리보기는 일부 파일만 보인다)
- [ ] "제출물 확정하고 문제풀기"

## 주의
- 확정 후에는 파일을 수정할 수 없다.
- 작업 시간이 끝나면 제출 안내가 자동으로 열린다. 그 전에 끝낸다.
- 서버를 띄운 터미널은 제출 전까지 닫지 않아도 된다. 제출물은 파일 기준이다.
