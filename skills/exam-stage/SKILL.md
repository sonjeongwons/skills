# 단계 안내

180분 과제를 8단계로 나눈 플레이북을 기준으로, 지금 위치와 다음 행동을 알려준다.
단계 전환은 사람이 정한다. 이 스킬은 판단 근거만 제공한다.

## 참고 파일

- 목차와 시간표: `__KIT_DIR__/playbook/00-timeline.md`
- 단계별 규칙: `__KIT_DIR__/playbook/01-environment.md` ~ `08-followup-qa.md`

## 절차

1. **시간 확인** — 사람에게 경과 시간(과제 타이머)을 묻거나, 사람이 말한 값을 쓴다. 모르면 추측하지 않는다.
2. **현재 단계 판단** — `00-timeline.md`의 시간표와 작업 폴더 상태로 판단한다.
   - `INTERVIEW.md`가 비었으면 2단계 이전
   - `AGREEMENT.md`에 담당자 확인 시각이 없으면 3단계 이전
   - 기능 커밋이 없으면 4단계 초반
   - `VERIFICATION.md` 성공 기준 표가 비었으면 5단계 이전
3. **해당 단계 파일 읽기** — `__KIT_DIR__/playbook/0N-*.md`의 "할 일"과 "종료 조건"을 읽는다.
4. **대조** — 종료 조건 각각을 작업 폴더의 실제 근거(파일 내용, `git log --oneline`)로 확인한다.
5. **보고**

```
경과: __분 / 현재 단계: N. ____ (권장 구간 __~__분)
종료 조건:
  [x] … (근거: 파일/커밋)
  [ ] … (부족한 점)
다음 행동 3개: …
넘지 말아야 할 선까지: 70분(v0) / 125분(새 기능 중단) / 170분(제출 시작) 중 가장 가까운 것 __분 남음
```

6. 시간이 권장 구간을 넘었으면 범위를 줄이는 선택지를 2개 이내로 제안한다. 결정은 사람이 한다.

- 종료 조건을 근거 없이 체크하기
