# 제출 전 점검

## 절차

1. **필수 제출물** — 과제 지시서(README)에서 필수 문서·파일명을 다시 읽고, 작업 폴더에 정확한 경로·이름으로 있는지 확인한다.

2. **git 상태**
   ```bash
   git status --short
   git log --oneline | head -20
   ```
   커밋되지 않은 변경이 있으면 목록으로 보고한다(커밋은 사람이 결정).

3. **문서와 구현 일치** — `HANDOFF.md`·필수 문서의 실행 명령, 파일명, 포트, 기능 상태가 실제와 같은지 확인한다. 다른 줄을 목록으로 보고한다.

4. **실행 재확인** — README에 적힌 실행·테스트 명령을 한 번 더 실행하고 결과를 요약한다.

5. **잔여물** — 작업 폴더에 `.env`, 키, 대용량 임시 파일, 디버그 출력 파일, 키트 원본 폴더(`kit/`)가 섞여 있지 않은지 확인한다. `skills/`와 `.agents/skills` 링크는 의도된 작업 도구이므로 남기되, README가 제출 범위를 제한하면 사람에게 알린다.

6. **보고**

```
[ ] 필수 파일: …
[ ] 커밋 안 된 변경: …
[ ] 문서-구현 불일치: …
[ ] 실행 재확인: 통과 / 실패(내용)
[ ] 잔여물: …
```

## 사람이 하는 일
- 에디터 탭이 모두 "저장됨"인지 확인 ("외부 변경 감지"가 있으면 비교 후 선택)
- 마지막 커밋 후 상단 "제출하고 문제풀기" → 미리보기 → "제출물 확정하고 문제풀기"
- 확정 후에는 수정할 수 없다
